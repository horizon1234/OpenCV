# 扩展课程说明

这批文件用于在不改动现有 01-16 节主程序的前提下，先把 17-50 节课程框架和实验代码沉淀到仓库中。

## 当前已补充内容

1. `17-60 OpenCV 图像学扩展课程总纲.md`
   - 给出 17-50 节完整主题规划
   - 每节包含核心 API、原理重点、实验目标

2. `advanced_lessons_demo.cpp`
   - 提供 17-60 节的可运行实验代码入口
   - 当前支持 lesson-id：17 ~ 60，每课支持 `demo-id=0/1`

3. 17-60 独立课程目录
   - 每节一个目录
   - 每节包含独立 markdown 讲义
   - 每节包含独立 `*_lesson_widget.h/.cpp` 课程页外壳文件

4. Qt 首页跳转
   - 17-60 节已经接入主程序首页
   - 可以像前 16 节一样在首页列表中点击进入对应课程页

## Linux 下编译示例代码

如果系统已经安装 OpenCV 4，可在项目根目录执行：

```bash
g++ -std=c++17 扩展课程/advanced_lessons_demo.cpp -o advanced_demo $(pkg-config --cflags --libs opencv4)
```

运行示例：

```bash
./advanced_demo cat.jpg 22
```

含义：

- `cat.jpg`：输入图像路径
- `22`：运行第 22 课 Canny 实验

## 后续建议

当前实现方式是：

1. 每课目录下保留自己的课程页外壳文件，保持和前 16 节一致的组织方式
2. 共享的算法演示逻辑集中在 `advanced_lesson_runtime.cpp`
3. 首页通过 `AdvancedLessonWidget` 动态生成 17-60 的课程页

如果你后面想继续“做厚”某一课，最自然的做法是：

1. 先在对应目录下把外壳类改造成独立大页面
2. 再把这节课从共享运行时里拆成专属实现
3. 最后再补更详细的配图、失败案例和保存结果逻辑
