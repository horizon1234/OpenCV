# 课程 20：锐化增强——拉普拉斯与自定义核

> 适合人群：已经理解平滑滤波，想进一步掌握“如何突出细节、边缘和局部对比”的学习者。

---

## 一、本课目标

本课要回答：

1. 为什么锐化本质上是在强调图像的快速变化。
2. 拉普拉斯算子为什么能突出边缘和细节。
3. 自定义锐化核应该怎么设计，为什么有些核会让图像变脏。
4. 锐化为什么总和噪声放大绑定出现。

---

## 二、锐化的本质

锐化不是凭空创造细节，而是放大原图中已经存在的局部差异。

如果某个区域亮度变化很快，锐化会让它更明显；如果某个区域本来很平滑，锐化的作用就小得多。

因此锐化天然偏向高频信息：

- 真实边缘是高频。
- 细纹理是高频。
- 噪声往往也是高频。

这就是为什么锐化常常一边提升视觉冲击力，一边把图像质量问题也同时暴露出来。

---

## 三、拉普拉斯算子的意义

拉普拉斯本质上是二阶导数思想，它关注的是“变化本身是否还在变化”。

在图像里，这使它对边缘、拐点和细节位置非常敏感。

常见离散形式如：

```text
0  -1   0
-1  4  -1
0  -1   0
```

或

```text
-1 -1 -1
-1  8 -1
-1 -1 -1
```

它们都会让局部变化被突出出来。

---

## 四、自定义锐化核怎么理解

典型锐化核通常满足两个特征：

1. 中心像素权重大。
2. 周围像素权重为负或较小。

这相当于在做一件事：

“保留中心，同时减去周围平均趋势。”

所以锐化本质上就是让当前位置更偏离周围背景，从而产生“更清晰”的视觉效果。

---

## 五、为什么锐化经常失败

### 1. 输入本身就很脏

噪声、压缩块、颗粒感都会被一起放大。

### 2. 核设计不合理

如果中心权重过大、负权重过强，结果会出现过冲、黑边、亮边或局部失真。

### 3. 输出类型处理错误

锐化结果中经常包含负值或超出 255 的值，如果直接截断到 8 位显示，会出现明显失真。

## 六、OpenCV API

```cpp
cv::Laplacian(src, dst, CV_16S, 3);
cv::filter2D(src, dst, -1, kernel);
```

教学上要强调：

- `Laplacian` 是现成的二阶导数实现。
- `filter2D` 允许你直接实验各种自定义锐化核。
- 做拉普拉斯时通常要使用更高精度中间结果，再转换回显示图像。

---

## 七、和上一课的关系

前两课讲的是平滑与去噪，本课讲的是增强。它们不是对立 API，而是图像频率操作的两端：

- 平滑抑制高频。
- 锐化强调高频。

因此一个成熟流程通常不是“只锐化”，而是：

1. 先控制噪声。
2. 再适度增强边缘和细节。

## 九、课堂实验建议

### 实验一：直接比较平滑与锐化

1. 先对同一张图做高斯平滑。
2. 再对原图做锐化。
3. 对比高频被压制和高频被放大的两种结果。

### 实验二：不同锐化核对比

1. 设计两组不同中心权重的 3x3 锐化核。
2. 观察边缘增强和噪声放大的差异。
3. 记录什么时候开始出现明显伪影。

### 实验三：先去噪再锐化

1. 给一张带噪声的图直接锐化。
2. 另一条分支先去噪再锐化。
3. 比较哪一种更适合作为工程流程。

## 十、工程实践提醒

1. 锐化从来不是万能增强，输入越脏，副作用越大。
2. 锐化参数必须和噪声水平一起考虑。
3. 若结果用于分割或检测，过度锐化可能制造伪边缘。
4. 自定义核实验时一定要同时保存原图、响应图、最终显示图。
5. 真正成熟的增强流程往往是“先稳住，再增强”，而不是一开始就猛拉细节。

---

## 十一、本课结论

1. 锐化本质上是在放大局部差异，而不是生成不存在的细节。
2. 拉普拉斯提供了经典的二阶导数增强思路。
3. 自定义锐化核的设计核心是中心增强与邻域抑制的平衡。
4. 锐化和噪声放大天然绑定，因此必须结合前处理和输出类型一起理解。
